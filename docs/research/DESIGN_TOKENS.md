# SpaceVibe Deck design tokens

- Frame: `min(100% - gutter * 2, 88rem)` with 1px white/12% rules.
- Background: `#0a0c0b`, `#090b0a`, and `#0c0e0c` neutral plates.
- Ink: white with 96%, 64%, 52%, and 45% opacity levels.
- Accent: achromatic white; product mockup uses a restrained Tokyo Night palette.
- Fonts: Apple/system sans for display and UI, SF Mono/JetBrains Mono fallback stack for terminal content.
- Breakpoints: 70rem for gutter reduction and 47.5rem for the mobile composition.
- Motion easing: `cubic-bezier(0.22, 0.78, 0.18, 1)`.
